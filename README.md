# Credit Risk Analysis (MS Excel)

## 📊 Project Overview
This project focuses on analyzing a credit risk dataset using Microsoft Excel. The objective is to understand customer demographics, financial behavior, employment patterns, and loan characteristics to identify high-risk customers and support data-driven decision-making in credit lending.

The project demonstrates an end-to-end analytics workflow including data cleaning, transformation, and dashboard creation using advanced Excel techniques.

---

## 🧰 Tools & Technologies
- Microsoft Excel
- Pivot Tables & Charts
- Advanced Excel Formulas (VLOOKUP, XLOOKUP, IF, Logical Functions)
- Data Cleaning & Transformation
- Lookup Tables

---

## 📂 Dataset Overview
The dataset contains customer credit information including:
- Demographics (Age, Gender, Marital Status)
- Banking Information (Checking & Savings Accounts)
- Employment Details
- Loan Information
- Credit History

---

## 🧹 Data Cleaning & Preparation
- Removed duplicates and inconsistencies  
- Handled missing values  
- Standardized data formats  
- Created categorized variables using binning techniques  
- Used lookup tables for structured classification  
- Applied data type corrections for analysis readiness  

---

## 📈 Dashboards & Key Areas

### 1. Customer Demographics
- Age, gender, marital status analysis
- Credit risk distribution across demographic groups

### 2. Financial Status
- Analysis of savings, checking accounts, and assets
- Identification of high-risk financial patterns

### 3. Employment & Loan Analysis
- Impact of employment duration and job type on credit risk
- Loan purpose and duration analysis

---

## 🔑 Key Insights
- Customers aged 19–29 show the highest credit risk contribution  
- Negative checking account balances strongly correlate with high default risk  
- Medium-term loans (13–24 months) show higher risk levels  
- Employment stability significantly impacts credit behavior  
- Loan purpose (e.g., new car loans) shows varying risk levels  

---

## 📌 Conclusion
This project demonstrates how Excel can be used for complete credit risk analysis through data cleaning, transformation, and visualization. The insights help identify high-risk customer segments and support better financial decision-making in lending processes.
